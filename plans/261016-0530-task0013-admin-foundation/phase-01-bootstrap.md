## Steps

1. `cd dau-viet-admin` — do **not** use `create-next-app` interactive prompt. Hand-write `package.json` with pinned deps (see D3), then `npm install` once to produce lockfile.
2. `tsconfig.json`: `"strict": true`, `"noUncheckedIndexedAccess": true`, `"exactOptionalPropertyTypes": true`, `paths: { "@/*": ["./src/*"] }`.
3. `tailwind.config.ts`: import tokens — `brand.red.700 #A51F18`, `surface.cream #FFFBF4`, `ink.primary #30251F`, `state.error #B3261E`, `heritage.gold.500 #E7B451`. Map to semantic color names (`brand`, `surface`, `ink`, `error`, `success`, `warning`); do not expose raw hex in components.
4. Fonts in `layout.tsx`: `Be_Vietnam_Pro` for body (`--font-sans`), `Noto_Serif` for headings (`--font-display`) via `next/font/google`, Vietnamese subset.
5. `src/env.ts`: zod schema `{ BACKEND_URL: z.string().url().default('http://localhost:8080'), NODE_ENV: z.enum(['development','test','production']) }`. Export parsed object; fail-fast on invalid.
6. `.env.example` — `BACKEND_URL=http://localhost:8080` only. No secrets.
7. shadcn: `npx shadcn@latest init` (or manual copy) — vendor primitives into `src/components/ui/`; only add what's needed this task (button, input, label, card, dialog, skeleton, dropdown-menu for user menu, sheet for mobile nav, toast via `sonner`).
8. npm scripts — `"dev":"next dev"`, `"build":"next build"`, `"start":"next start"`, `"lint":"next lint"`, `"typecheck":"tsc --noEmit"`, `"test":"vitest"`, `"test:e2e":"playwright test"`.

## Tests

## Success criteria

- `npm ci` clean, `npm run lint`/`typecheck`/`build` exit 0.
- `next dev` boots on `:3000`, `/` redirects to `/dashboard` (which will 404 → login for now; that's fine).
- Lockfile committed.

## Risks

- Tailwind 4 vs 3.4: pin 3.4 exactly. If shadcn CLI demands 4, install `tailwindcss@3.4` manually and write `tailwind.config.ts` by hand.
- `next/font/google` requires network at build; if blocked, fallback to system font stack — keep `--font-sans`/`--font-display` CSS vars anyway.
