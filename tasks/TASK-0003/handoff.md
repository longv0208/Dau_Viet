## Assumptions and invariants

- Runner executes under both `pwsh` 7+ and `powershell.exe` 5.1; no `Invoke-Expression`.
- `docs/PROGRESS.md` is view-only; `task.json` remains source of truth.
- `finish` never auto-commits; user controls git.
- Evidence staleness: any tracked/staged/untracked input change, HEAD move, or config hash change invalidates prior verify.
- `done` is a terminal state — `Test-StatusTransition` refuses `done → *`. Refinish requires reverting status first.
- AC coverage is a finish-time blocker, not optional.
